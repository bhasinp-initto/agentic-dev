## Task 1: State transition helpers

**Files:** queue-set-status.sh, circuit-breaker.sh, cleanup-completed-goal.sh + tests.

### queue-set-status.sh `<goal-id> <new-status> [field1=value1 ...]`

- Read .claude/agentic/queue.yaml
- Find the goal with the given id
- Set status = new-status; set any extra field=value pairs (started_at, completed_at, halted_at, baseline_ref, head_ref, manifest_path, worktree_path — anything in queue.schema.json v0.2)
- Validate result against queue.schema.json
- Write back (atomic: write to .tmp then mv)
- On validation failure → error to stderr, exit 1, leave queue.yaml untouched

### circuit-breaker.sh `<new-state> [halted_reason=...] [halted_goal_id=...]`

- Read .claude/agentic/state.json
- Set circuit_breaker.state = new-state (idle | running | halted | completed)
- If new-state == halted: also require halted_reason and halted_goal_id; populate halted_at = current UTC
- Update last_updated
- Validate against state.schema.json
- Atomic write

### cleanup-completed-goal.sh `<goal-id>`

- Verify goal in queue has status=completed
- Call bin/worktree-cleanup.sh <goal-id>
- Print summary

**Tests** (each helper):
- Happy path (status flip valid)
- Invalid new-status enum (refused)
- Missing goal-id (refused)
- Validation failure → original file untouched
- Cleanup: refuses if goal not completed

**Steps:** 1. Write tests, 2. Implement helpers, 3. Run tests until green, 4. Commit `feat(phase-6): queue + state-machine helpers`.

## Task 2: _advance-goal skill

**File:** `agentic-dev/skills/_advance-goal/SKILL.md`.

**Behavior** (per design §5):

1. $ARGUMENTS = goal-id; refuse if empty
2. Read queue.yaml; verify goal exists with status=approved; refuse otherwise
3. Capture current HEAD as baseline_ref (using `git rev-parse HEAD`)
4. Call `bin/queue-set-status.sh <id> running started_at=<now> baseline_ref=<sha>`
5. Call `/agentic-dev:_run-implementer <spec-path>`
   - If implementer exits non-zero → halt: queue-set-status halted; circuit-breaker halted; exit 1
6. Call `/agentic-dev:_run-gates <id>`
   - If gates fail → halt path (escalation already generated by _run-gates); circuit-breaker halted; exit 1
7. Call `/agentic-dev:_run-reviewer <id>`
   - If exits 0 + no auto-fix-queue file → clean path (step 8)
   - If exits 0 + auto-fix-queue exists → auto-fix loop (step 8a)
   - If exits 1 → halt path

8. **Clean path:**
   - queue-set-status.sh <id> completed completed_at=<now> head_ref=<sha> manifest_path=<path>
   - bin/cleanup-completed-goal.sh <id>
   - bin/telegram-notify.sh digest "Goal <id> completed cleanly"
   - exit 0

8a. **Auto-fix loop** (rounds 1-2, hard cap):
   - Read .claude/agentic/auto-fix-queue/<id>.json — list of mechanical concerns
   - Re-dispatch /agentic-dev:_run-implementer with addendum: "Address these concerns from review: <concerns list>"
   - Re-run /agentic-dev:_run-gates and /agentic-dev:_run-reviewer
   - If clean → step 8 clean path
   - If still has auto-fix-queue → round 2 (same logic)
   - If round 2 also has auto-fix-queue → escalate as `auto_fix_exhausted`
   - Track round count in a local variable

9. **Halt path** (any failure):
   - queue-set-status.sh <id> halted halted_at=<now> (head_ref + manifest_path if available)
   - circuit-breaker.sh halted halted_reason="<descriptive>" halted_goal_id=<id>
   - exit 1

**Structural test:** parse SKILL.md, assert presence of: $ARGUMENTS, queue-set-status, circuit-breaker, _run-implementer, _run-gates, _run-reviewer, auto-fix loop with cap 2, clean path, halt path, cleanup-completed-goal, telegram-notify.

**Commit:** `feat(phase-6): /agentic-dev:_advance-goal skill (single-goal pipeline)`

## Task 3: _run-orchestrator skill

**File:** `agentic-dev/skills/_run-orchestrator/SKILL.md`

**Behavior** (per design §6):

1. Pre-check: state.json's circuit_breaker.state in {idle, running}. If halted/completed → refuse with reason.
2. Read queue.yaml; find first goal with status=approved
3. If no approved goals:
   - Note any drafted/intent_only counts; print "Queue idle"; exit 0
4. Set circuit_breaker.state = running (via circuit-breaker.sh) if currently idle
5. Call `/agentic-dev:_advance-goal <id>`
6. On _advance-goal exit 0:
   - Use ScheduleWakeup with delay=30s and prompt-to-resume = "/agentic-dev:_run-orchestrator"
   - Exit 0 (next wakeup picks up the next goal)
7. On _advance-goal exit 1: circuit breaker is already halted by the goal; print summary; exit 1

Note: When the queue is empty AND circuit_breaker is running, set circuit_breaker.state = completed (queue exhausted cleanly). Or revert to idle — design choice. v0.6 uses `idle` (ready for more work).

**Structural test:** assert presence of: $ARGUMENTS handling (empty=normal), circuit-breaker pre-check, first-approved-goal lookup, _advance-goal dispatch, ScheduleWakeup integration, exhaustion handling.

**Commit:** `feat(phase-6): /agentic-dev:_run-orchestrator skill`

## Task 4: Public start + resume skills

**Files:** `agentic-dev/skills/start/SKILL.md`, `agentic-dev/skills/resume/SKILL.md`.

### start

```
Usage: /agentic-dev:start [--until <HH:MM | <N>m | <N>h>]
```

1. Pre-checks: circuit_breaker not halted (else refuse with /agentic-dev:resume hint)
2. If --until provided: parse + write target wake cutoff to state.json (new optional field: `state.target_cutoff_at`)
3. circuit-breaker.sh running
4. Invoke /agentic-dev:_run-orchestrator

### resume

```
Usage: /agentic-dev:resume <decision> [args]
Decisions: resume | skip | address | replan | abort
```

1. Pre-check: circuit_breaker.state == halted (else refuse)
2. Read state.json's halted_goal_id
3. Log decision + args to `.claude/agentic/decisions.log`
4. Per decision:
   - `resume`: queue-set-status.sh halted_goal approved; circuit-breaker idle; tell user to run /agentic-dev:start to continue
   - `skip`: queue-set-status.sh halted_goal abandoned; circuit-breaker idle; orchestrator can continue
   - `address <concern-resolution-text>`: log; queue-set-status approved; same as resume
   - `replan`: queue-set-status drafted (re-engages drafter); reset spec's approved=false (Edit tool); circuit-breaker idle
   - `abort`: circuit-breaker completed; queue advances no further

**Tests:** structural for both skills.

**Commit:** `feat(phase-6): /agentic-dev:start + /agentic-dev:resume public skills`
